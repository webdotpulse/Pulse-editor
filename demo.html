Pulse Editor 2.0

AI-Powered Rich Text & Code Editor • Lightweight & Dependency-Free

Welkom bij Pulse Editor 2.0

Pulse Editor is een geavanceerde, lichtgewicht en afhankelijkheidsvrije rich text en code editor, uitgerust met Google Gemini 2.5 Generative AI mogelijkheden.

"Selecteer willekeurige tekst om de zwevende bubble-toolbar te zien of gebruik de magische AI-tools in de toolbar!"

Belangrijkste Mogelijkheden

  • Generatieve AI Suite: Grammatica verbeteren, Samenvatten, Schrijfstijl / Toon wijzigen, Tekst Uitbreiden, Vertalen en SEO-optimalisatie.
  • Zwevende Bubble Toolbar: Snelle opmaak direct boven geselecteerde tekst.
  • Afbeeldingen & Tabellen: Klik op afbeeldingen voor schaal- en uitlijnopties; voeg responsieve tabellen in.
  • Code Modus: Volledige syntaxkleuring voor JavaScript, HTML, CSS, Python, PHP & JSON met regelnummers en code-folding.
  • Zoeken & Vervangen: Zowel in Rich Text als in Code Mode zonder DOM-verlies.
